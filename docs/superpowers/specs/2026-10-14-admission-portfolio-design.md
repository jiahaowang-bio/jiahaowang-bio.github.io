# 保研个人展示网站设计

用户已确定保研用途，保留首页简介与 CV，新增学业成绩、经历、探索。探索同时包括科研阅读与自主研究、技术项目与实践尝试。

沿用 PRISM 的多页布局和已有文本、卡片页面，不添加新的页面类型。首页参照用户提供截图采用宽两栏：左侧 300px 头像、身份和研究兴趣，右侧简介和展示内容卡片。导航顺序为首页、学业成绩、经历、探索、简历/CV。默认中文，关闭点赞，支持中英文切换并记住选择。

简介与 CV 使用 Markdown；三个新增栏目使用 TOML 卡片配置。个人身份、成绩、排名、项目和经历均使用明确标注的待填写内容，不编造事实。使用通用头像占位图，空联系方式不显示。

验收：静态构建成功；五个栏目可访问；导航及首页栏目链接正常；手机菜单可使用；深浅主题下内容可读；旧示例身份及论文不出现在导出页面中。
